Contributing

Thank you for your interest in contributing to AI Workflow Templates.

We welcome contributions that improve the quality, usability, and value of this repository.

Ways to Contribute

You can contribute by:

* Adding new workflow templates
* Improving existing workflows
* Fixing bugs
* Improving documentation
* Sharing best practices
* Reporting issues

Before You Contribute

Please ensure:

* Workflows are tested before submission
* Sensitive information such as API keys is removed
* Documentation is included
* File naming conventions are followed

Workflow Folder Structure

Each workflow should contain:

workflow.json (or blueprint)
README.md
screenshot.png
config-example.json (optional)

Naming Convention

Examples:

n8n-ai-blog-writer
n8n-lead-generator
make-content-calendar
make-instagram-automation

Use descriptive names.

Avoid:

workflow1
test
new-workflow
sample

Submission Process

1. Fork the repository
2. Create a new branch

git checkout -b feature/my-workflow

3. Commit your changes

git commit -m "Added AI blog writer workflow"

4. Push the branch

git push origin feature/my-workflow

5. Open a Pull Request

Pull Request Checklist

Before submitting:

* Workflow tested
* Documentation added
* Screenshots included
* No secrets included
* Folder structure followed

Reporting Issues

If you discover a bug or problem:

* Open a GitHub Issue
* Describe the problem clearly
* Include screenshots if available
* Provide reproduction steps

Code of Conduct

Please be respectful and constructive when interacting with other contributors.

Thank You

Your contributions help make AI Workflow Templates a valuable resource for the automation community.
